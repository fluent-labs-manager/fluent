# Данные

Данные приходят из временных заглушек. Слой данных устроен так, чтобы при подключении API менялись только функции в `src/api/`, а страницы и компоненты оставались как есть.

## Как устроено

```text
src/mocks/*.ts            моковые данные
        ↓
src/api/<раздел>/*Api.ts  функции получения данных (сейчас заглушки *Stub)
src/api/<раздел>/*.dto.ts типы данных: User, AccountProfile, Course, Semester, TaughtCourse, Lab, CourseLabs, LabSubmission
        ↓
src/stores/user.ts        текущий пользователь (Pinia) — нужен меню и страницам
src/composables/*.ts      данные страницы: useSemesters() → semesters, isLoading, error, reload
                          useCourseLabs(courseId) → courseLabs, isLoading, error, reload
                          useLabSubmission(courseId, labId) → submission, isLoading, error, reload
                          useAccountProfile() → profile, isLoading, error, reload
                          useTaughtCourses(enabled) → courses, isLoading, error, reload
                          useNow() → текущее время, обновляется раз в минуту
        ↓
src/views/*.vue           страницы: состояния загрузки, ошибки и пустого списка
        ↓
src/components/*.vue      компоненты получают данные только через props
```

- Компоненты и страницы не импортируют `src/mocks/` напрямую — только заглушки в `src/api/` знают о моках.
- Ошибки загрузки ловятся там, где данные загружаются: в [`useSemesters`](../src/composables/useSemesters.ts), [`useCourseLabs`](../src/composables/useCourseLabs.ts) и в [хранилище пользователя](../src/stores/user.ts). Текст `ApiRequestError` показывается пользователю, для остальных ошибок — общее сообщение.
- Заглушки бросают `ApiRequestError`, как [ApiResolver](./utils/ApiResolver.md), поэтому обработка ошибок уже рассчитана на настоящие запросы.
- Даты в DTO имеют тип [`IsoDateTime`](../src/types/IsoDateTime.ts): дата, время и часовой пояс в формате ISO 8601. Получить его можно только через [`toIsoDateTime`](../src/utils/IsoDateTime.ts) — она бросает ошибку на дате без времени, без часового пояса или с несуществующим днём. В моках даты создаются через неё же; когда появится API, даты из ответа нужно пропускать через неё в `src/api/`.

## Статусы лабораторных работ

| Статус           | Бейдж         | Поля                                     |
|------------------|---------------|------------------------------------------|
| `submitted`      | «Сдано»       | `variant`, `grade`, `submittedAt`        |
| `pending-review` | «На проверке» | `variant`, `submittedAt`, оценки ещё нет |
| `not-submitted`  | «Не сдано»    | `variant`                                |
| `locked`         | «Недоступно»  | —                                        |

Выполненной считается только работа со статусом `submitted`: работа на проверке в прогресс «1 из 3 выполнено» не входит.

Значения статусов заданы один раз в [`LabStatus`](../src/types/LabStatus.ts). В коде используйте `LabStatus.Submitted`, `LabStatus.NotSubmitted` и т. д., а не строки.

## Карточка работы

Страница показывает одну карточку с работой: номер, название, срок или статус, выданный вариант и кнопки. Какую работу показать, студент выбирает нажатием в списке «Все работы дисциплины»:

- выбрать можно любую работу, кроме недоступной (`locked`): несданную, в том числе с прошедшим сроком, сданную и на проверке;
- выбранная работа подсвечена в списке и записана в адрес — `/courses/2?lab=204`, поэтому выбор переживает перезагрузку;
- пока студент ничего не выбрал (или в адресе работа, которую выбрать нельзя), карточка показывает несданную работу с ближайшим непрошедшим сроком; если таких нет — несданную с прошедшим сроком; если нет и их — самую раннюю по номеру. Правило — [`getDefaultLab`](../src/utils/LabSelection.ts);
- если выбрать нечего, вместо карточки — «Активных работ нет.».
- кнопка в карточке ведёт на страницу лабораторной `/courses/:courseId/labs/:labId`: у несданной работы, в том числе после срока, — «Сдать работу», у остальных — «Открыть работу». «Назад» на странице лабораторной возвращает к дисциплине с этой же работой в карточке.

Срок сдачи в карточке и в списке сравнивается с временем из [`useNow`](../src/composables/useNow.ts), поэтому на открытой странице он становится красным и меняется на «Срок истёк» без перезагрузки.

## Страница лабораторной

`/courses/:courseId/labs/:labId` загружает работу вместе с попытками сдачи — [`LabSubmission`](../src/api/labs/LabSubmission.dto.ts). Каждая попытка ([`LabAttempt`](../src/api/labs/LabAttempt.dto.ts)) — один файл (имя и размер в байтах), комментарий студента, комментарий преподавателя и результат:

| Результат  | Бейдж         |
|------------|---------------|
| `rejected` | «Отклонено»   |
| `pending`  | «На проверке» |
| `accepted` | «Принято»     |

Значения заданы в [`AttemptResult`](../src/types/AttemptResult.ts). Отклонённую работу возвращают студенту: её статус снова `not-submitted`, а «Отклонено» остаётся только у попытки в истории.

Что показывает страница:

- `not-submitted` — область для файла, комментарий, «Отправить работу на проверку» (без файла неактивна) и «Сохранить черновик». Выбор файла и отправка пока не работают;
- `pending-review` и `submitted` — только просмотр: последний отправленный файл, у сданной рядом со статусом оценка;
- `locked` — «Работа пока недоступна», без файлов и истории;
- справа — «История»: попытки, последняя сверху.

Попытки в моках: у работы 102 — две отклонённые, у 202 — одна на проверке, у 101 — принятая ([`src/mocks/labAttempts.ts`](../src/mocks/labAttempts.ts)). Работа другой дисциплины или несуществующая — ошибка «Работа не найдена».

## Режимы моков

Чтобы увидеть состояния страницы без бэкенда, добавьте параметр:

| Адрес                              | Что покажет страница                                 |
|------------------------------------|------------------------------------------------------|
| `/account`                         | Личный кабинет студента                              |
| `/account?role=teacher`            | Личный кабинет преподавателя и его меню              |
| `/account?mock=error`              | Ошибку «Сервис временно недоступен» и кнопку повтора |
| `/account?role=teacher&mock=empty` | Кабинет преподавателя без дисциплин                  |

Роль из `?role=teacher` запоминается до закрытия вкладки, как будто пришла в токене: ссылки внутри приложения этот параметр теряют. Вернуться к студенту — `?role=student`.

Режимы и задержка заданы в [`src/mocks/mockMode.ts`](../src/mocks/mockMode.ts).

# Данные

Данные приходят из временных заглушек. Слой данных устроен так, чтобы при подключении API менялись только функции в `src/api/`, а страницы и компоненты оставались как есть.

## Как устроено

```text
src/mocks/*.ts            моковые данные
        ↓
src/api/<раздел>/*Api.ts  функции получения данных (сейчас заглушки *Stub)
src/api/<раздел>/*.dto.ts типы данных: User, Course, Semester
        ↓
src/stores/user.ts        текущий пользователь (Pinia) — нужен меню и страницам
src/composables/*.ts      данные страницы: useSemesters() → semesters, isLoading, error, reload
        ↓
src/views/*.vue           страницы: состояния загрузки, ошибки и пустого списка
        ↓
src/components/*.vue      компоненты получают данные только через props
```

- Компоненты и страницы не импортируют `src/mocks/` напрямую — только заглушки в `src/api/` знают о моках.
- Ошибки загрузки ловятся там, где данные загружаются: в [`useSemesters`](../src/composables/useSemesters.ts) и в [хранилище пользователя](../src/stores/user.ts). Текст `ApiRequestError` показывается пользователю, для остальных ошибок — общее сообщение.
- Заглушки бросают `ApiRequestError`, как [ApiResolver](./utils/ApiResolver.md), поэтому обработка ошибок уже рассчитана на настоящие запросы.

## Режимы моков

Чтобы увидеть состояния страницы без бэкенда, добавьте параметр:

| Адрес                 | Что покажет страница                                     |
|-----------------------|----------------------------------------------------------|
| `/courses`            | «Загрузка дисциплин…», затем данные (задержка ~0,7 с)    |
| `/courses?mock=empty` | «Дисциплин пока нет.»                                    |
| `/courses?mock=error` | Ошибку «Сервис временно недоступен» и кнопку повтора     |

Режимы и задержка заданы в [`src/mocks/mockMode.ts`](../src/mocks/mockMode.ts).

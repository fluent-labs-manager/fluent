# Стили

Глобальные стили, дизайн-токены и подключение шрифтов находятся в [`src/assets/base.css`](../src/assets/base.css). Файл импортируется один раз в `src/main.ts` и действует на всё приложение.

## Глобальные правила

- `box-sizing: border-box` для всех элементов.
- У `body` убран отступ по умолчанию, заданы фон, цвет текста и основной шрифт.
- `button` и `input` наследуют шрифт от родителя.

## Токены

В компонентах используйте токены, а не числа и hex-значения. Если нужного значения нет, добавьте новый токен в `base.css`, а не пишите число в компоненте.

### Цвета — `--color-*`

| Токен                     | Назначение                                     |
|---------------------------|------------------------------------------------|
| `--color-bg`              | Фон страницы                                   |
| `--color-surface`         | Фон карточек и кнопок                          |
| `--color-sidebar`         | Фон бокового меню                              |
| `--color-muted-surface`   | Фон полосы прогресса, пункт меню при наведении |
| `--color-accent-surface`  | Активный пункт меню, фон переключателя         |
| `--color-summary`         | Фон блока «Прогресс семестра»                  |
| `--color-border`          | Рамки                                          |
| `--color-text`            | Основной текст                                 |
| `--color-text-secondary`  | Второстепенный текст                           |
| `--color-accent`          | Акцент: прогресс-бар, иконки, значения         |
| `--color-success`         | Положительный статус (процент выполнения)      |
| `--color-error`           | Ошибки, близкий срок сдачи, бейдж «Не сдано»   |
| `--color-deadline`        | Срок сдачи, до которого три и более суток      |
| `--color-success-surface` | Фон бейджей «Сдано» и «1 из 3 выполнено»       |
| `--color-success-text`    | Текст на фоне `--color-success-surface`        |
| `--color-review-surface`  | Фон бейджа «На проверке»                       |
| `--color-review`          | Текст бейджа «На проверке»                     |
| `--color-error-surface`   | Фон бейджа «Не сдано»                          |
| `--color-locked-surface`  | Фон бейджа «Недоступно»                        |
| `--color-locked`          | Текст бейджа «Недоступно»                      |

### Тени — `--shadow-*`

| Токен             | Назначение                                  |
|-------------------|---------------------------------------------|
| `--shadow-card`   | Карточки и крупные блоки                    |
| `--shadow-raised` | Приподнятые элементы (выбранная кнопка)     |

### Размеры шрифта — `--font-size-*`

| Токен              | Размер | Где используется                           |
|--------------------|--------|--------------------------------------------|
| `--font-size-xs`   | 12px   | Подписи, группа пользователя               |
| `--font-size-sm`   | 13px   | Второстепенный текст в карточках           |
| `--font-size-md`   | 14px   | Кнопки, имя пользователя                   |
| `--font-size-lg`   | 15px   | Имя преподавателя                          |
| `--font-size-xl`   | 17px   | Пункты меню                                |
| `--font-size-2xl`  | 18px   | Название курса                             |
| `--font-size-3xl`  | 20px   | Заголовки блоков, название работы          |
| `--font-size-4xl`  | 30px   | Логотип, номер варианта                    |
| `--font-size-5xl`  | 40px   | Заголовок страницы                         |

### Раскладка страницы

Эти токены общие для бокового меню и страниц. Благодаря им логотип стоит на одном уровне с заголовком страницы, а первая строка под заголовком — на уровне первого пункта меню.

| Токен                      | Значение | Назначение                                          |
|----------------------------|----------|-----------------------------------------------------|
| `--page-offset-top`        | 24px     | Отступ сверху у меню и у страницы                   |
| `--page-title-line-height` | 44px     | Высота строки логотипа и заголовка страницы         |
| `--page-header-gap`        | 40px     | Отступ под логотипом и под заголовком страницы      |
| `--nav-item-height`        | 48px     | Высота пункта меню и строки под заголовком страницы |

Меняйте их только в `base.css` — иначе выравнивание меню и страницы собьётся. Новые страницы должны использовать `--page-offset-top` в верхнем отступе и `--page-title-line-height` у заголовка `h1`.

## Шрифты

Основной шрифт — **SF Pro Display**, начертания 400, 500 и 700 в формате `woff2`. Файлы лежат в [`src/assets/fonts/`](../src/assets/fonts) и подключаются через `@font-face` в `base.css`.

- Шрифты хранятся в `src/assets`, а не в `public/`: Vite добавляет их в сборку с хешем в имени, поэтому после обновления файла браузер не возьмёт старую версию из кэша.
- Начертания 800 нет: `font-weight: 800` отрисуется как 700.
- Если шрифт не загрузился, используются системные: `-apple-system`, `Segoe UI`, `Roboto`.
- Лицензия SF Pro разрешает использование только в интерфейсах для платформ Apple. Перед публикацией проекта это нужно учитывать.

# Документация

Этот каталог содержит техническую документацию по утилитам и компонентам проекта. Используйте этот файл как точку входа для навигации по разделам.

## Стили

- [Стили](./styles.md) — глобальные стили, дизайн-токены (цвета, тени, размеры шрифта, раскладка страницы) и шрифты.

## Утилиты

- [ApiResolver](./utils/ApiResolver.md) — выполнение HTTP-запросов, обработка ответов и ошибок, преобразование DTO в `FormData` и `URLSearchParams`.
